# sentinel-audit

Multi-Agent AI Security Orchestration Framework for automated smart contract security analysis using graph-based collaborative agent workflows.

### Overview

`sentinel-audit` is an experimental AI-driven security orchestration framework designed to explore collaborative reasoning patterns for automated smart contract analysis.

The system coordinates multiple specialized AI agents using graph-based orchestration workflows to:
- decompose complex security analysis tasks,
- validate reasoning iteratively,
- reduce hallucinated findings,
- and improve structured security evaluation workflows.

The project focuses on combining:
- Agentic AI systems
- Multi-agent orchestration
- Structured LLM outputs
- Validation-oriented reasoning
- Adversarial analysis workflows

---
## Architecture

The framework is built around collaborative AI agents with distinct responsibilities:

- **Strategist Agent**
  - Breaks down audit objectives
  - Generates analysis plans
  - Coordinates workflow execution

- **Adversary Agent**
  - Performs adversarial reasoning
  - Explores exploitability paths
  - Challenges assumptions

- **Validator Agent**
  - Validates findings
  - Performs consistency checks
  - Reduces hallucinated outputs

Agents communicate through structured Pydantic-based schemas to ensure deterministic and machine-readable interactions.
